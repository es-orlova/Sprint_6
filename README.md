# Sprint_6 Автотесты для сервиса "Яндекс.Самокат"
Учебный проект, содержащий UI-автотесты на Python для сервиса аренды самокатов "Яндекс.Самокат".

Тестируемый сайт: https://qa-scooter.praktikum-services.ru/

Технологии и Библиотеки
Python 
Selenium (для взаимодействия с браузером)
Pytest (для запуска тестов и фикстур)
Allure-Pytest (для генерации отчетов)
Webdriver-manager (для автоматического управления geckodriver)
Mozilla Firefox (в качестве основного браузера для тестов)

Структура проекта
Проект реализован с использованием паттерна Page Object Model (POM).

├── locators/                  # Директория с локаторами элементов
│   ├── main_locators.py        # Локаторы для главной страницы

├── pages/                     # Директория с классами Page Object

│   ├── main_page.py            # Методы для главной страницы
│   └── order_page.py           # Методы для страниц флоу заказа
├── test_data/                 # Директория с тестовыми данными
│   └── order_data.py           # Данные для тестов заказа
├── tests/                     # Директория с тестами
│   ├── test_faq.py             # Тесты для раздела "Вопросы о важном"
│   ├── test_order_flow.py      # Тесты для флоу заказа

Тестовые сценарии
Проект покрывает следующие позитивные сценарии:
Тестирование аккордеона "Вопросы о важном" (test_faq.py):
 Проверяется, что при клике на каждый из 8 вопросов в списке, открывается соответствующий ему текст ответа.
Тест параметризован для проверки всех 8 пар "вопрос-ответ".
Тестирование флоу заказа самоката (test_order.py):
 Проверяется полный позитивный сценарий заказа.
Тест параметризован для двух точек входа: кнопка "Заказать" вверху страницы и кнопка "Заказать" внизу страницы.
Тест параметризован для двух разных наборов тестовых данных (USER_1 и USER_2).
 По итогу проверяется, что появляется модальное окно "Заказ оформлен".
Тестирование ссылок в хедере (test_links.py):
 Проверяется, что клик по логотипу "Самокат" возвращает пользователя на главную страницу.
 Проверяется, что клик по логотипу "Яндекс" открывает в новой вкладке главную страницу "Дзен" (dzen.ru).
